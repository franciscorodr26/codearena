# Contributors

CodeArena was built by a small team between August 2025 and September 2026.

The original repository cannot be made public because it was shared with a
private product, so this public history was rebuilt. Each person below has their
own commit, authored under their GitHub account, containing the files they are
the primary author of (measured with `git blame` on the original history). The
numbers in the table come from the original history and are the real totals,
not the size of the rebuilt commits.

Lines are hand-written code only: dependencies, lockfiles, generated data,
coverage reports, images and JSON data files are excluded.
